# §116 — Единый автономный PostgreSQL-контроль 9 SQL-черновиков AI v2.1

**Scope:** Disposable localhost PostgreSQL only; **NO-GO** for Supabase/Edge/production.

Тест `qa/sql_drafts/iclub_ai_v21_nine_drafts_integrated_local_pg.psql` подготавливает минимальный синтетический академический каркас и настоящую сохранённую v1 tariff foundation migration, затем **в одной транзакции** загружает девять существующих `*_UNAPPLIED.sql` строго по графу зависимостей. Проверяет наличие 23 server RPC, запрет выполнения от anon/authenticated, server-only grants, запрет прямого изменения защищённых приватных таблиц, глобальный kill switch, release OFF, закрытый navigation source, невозможность provider spend без разрешения. Наконец выполняет `ROLLBACK` и удостоверяется, что все новые объекты исчезли, а исходная v1 foundation сохранилась с AI=OFF.

**Важно:** это НЕ точный клон текущей Supabase: несколько v1 security/subject сервисов в стенде — намеренно всегда отказывающие синтетические заглушки; недостающее `global_ai_rollout_mode` в v1 foundation введено только в одноразовом стенде. Проверка выполняется как новый 15-й независимый PostgreSQL-набор в привычной GitHub Actions, без Vercel, provider, Supabase branches. До реального выпуска требуется реальный integrated protected Preview и независимый аудит RLS/transaction/concurrency и editorial rights.

**CI:** [GitHub Actions #340, повторный прогон 2](https://github.com/jteshaboev1984-ops/iClub_APP/actions/runs/38699714767) — **GREEN**, **664/664 Node** и **15/15 независимых PostgreSQL**. `INTEGRATED_NINE_DRAFTS_GREEN` подтвердил все 23 функции и server-only permissions, `INTEGRATED_NINE_ROLLBACK_GREEN` подтвердил отсутствие новых объектов после отката и сохранившийся baseline AI=OFF. Chromium RU/UZ/EN, Deno и конкурентные тесты также прошли. Первый прогон этого же commit остановился раньше на не запустившемся Chrome CDP (20 секунд); повторный без изменения кода прошёл.

### Дополнительная точная сверка production metadata (READ-ONLY)

После GREEN отдельно считаны **89 определений столбцов десяти критических таблиц** через `information_schema.columns` — никаких строк учеников. В сравнении с *намеренно минимальной* synthetic fixture и v1 foundation обнаружены **49 отсутствующих либо несовпадающих по типу столбцов**. Полный датированный перечень: `qa/ai-layer-v21-p9-production-schema-shape-readonly.json`. Среди не смоделированных обязательных полей — Practice answer `is_correct`, `answered_at` и реальные поля пользователей; ряд полей Tour/Practice и коммерческого runtime тоже сокращён. Эти различия **не означают дефект production-схемы**; они подтверждают, что нынешний тест действительно не является production-клоном и не проверяет все runtime-вызовы девяти функций. Нельзя использовать GREEN как разрешение развёртывания.

**Следующий обязательный крупный допуск:** построить отдельный synthetic *полный* compatibility fixture по 89 метаданным полям и актуальным ограничениям, проверить положительные/отрицательные RPC пути и RLS с двумя владельцами, transactional rollback и обязательные клиентские запреты. После этого — отдельный защищённый интегрированный Preview и отдельный owner GO. До этого Global AI OFF / NO-GO.
