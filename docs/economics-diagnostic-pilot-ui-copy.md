# Economics Diagnostic Pilot — Student-Facing UI Copy Draft

Date: 2026-07-03

Use simple student-facing wording. Do not expose internal system names.

## Correct answer feedback

```text
Correct. You understood the main idea.
```

Optional next action:

```text
Now try one more similar question to make sure the skill is stable.
```

## Incorrect answer feedback

```text
Not quite. Your answer shows which part needs revision.
```

Then show:

```text
Weak area: [topic / subtopic]
Next step: [short recommended action]
```

## Input answer with units accepted

For cases like answer `3`, where the user writes `3 units Y`:

```text
Correct. We accepted your answer because it has the right value with units.
```

## Input answer wrong calculation

```text
Check the calculation again. Divide the amount sacrificed by the amount gained.
```

## Policy

Feedback should help the student understand the mistake.

Do not shame the student.
Do not use internal diagnostic labels.
Do not reveal answer keys before submission.
