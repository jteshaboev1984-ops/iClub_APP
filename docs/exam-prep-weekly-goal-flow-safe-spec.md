If already finalized but objective task or mandatory written work was incomplete/unsuccessful, offer **the same pack** deliberately as *repeat learning*, with a clear RU/UZ/EN notice before the first item. Correction remediation still needs 3/3 correct objective analogues + a saved written response; correction closure still requires a **different, delayed, fresh retest**. P1 evidence cannot credit P5.

6. At a completed-week boundary, show prior-week warning only with exact frozen goal and verified evidence; ambiguous older plan means no verdict. Never change grade, exam series, weekly hours or stage automatically. Allow learner adjustments only in existing Exam Plan editor.
7. Render one visible CTA per verified goal and no duplicate native rows; keyboard/touch access, symmetric phone/desktop, natural RU/UZ/EN. On an uncertain server response do not invent status or a task.
