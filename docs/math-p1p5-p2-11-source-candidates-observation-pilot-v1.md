# Mathematics P1/P5 — P2-11: источник заданий и проверяемые наблюдения времени

**Дата:** 03.11.2026. **Issue:** #450. **Draft PR:** #470. **Этап:** академическая подготовка измерения трудоёмкости; не утверждение норм и не запуск ученической функции.

## 1. Результаты определяют действия, действия определяют будущие минуты

Применяется принятое архитектором решение P2-09/P2-10: из реального серверного статуса ученика берутся только ещё необходимые действия по навыкам. Не считаем одинаковый полный цикл обучения каждому из 81 навыков. Пять ошибок в одном навыке не становятся пятью новыми уроками. Непроверенное остаётся непроверенным. Исправленный и подтверждённый навык больше не должен накапливать старые ошибки. Отдельные данные P1 и P5, общий Mathematics календарный бюджет и неизменяемая история результатов сохраняются.

Время можно рассчитывать после проверки **активной самостоятельной работы**, а не из количества неправильных ответов, ограничений таймера вопроса или исторических Cambridge guided learning hours. Оценка должна охватывать работу над методом, исправление, повторную проверку и перенос навыка в новые задания; тип работы может менять необходимую продолжительность.

## 2. Проверка реальных материалов, а не выдуманные задания

Источник: официальная программа Cambridge Mathematics 9709 2026–2027, одобренные карты 81 навыка и приватная проверка QA-публикации внутри iClub. Агрегированный SELECT-only запрос к действующей БД показал: все **45 навыков P1** и все **36 навыков P5** имеют опубликованный маршрут диагностики, обучения, повторной проверки, смешанных задач и письменных работ. Это подтверждает наличие **кандидатов** для академического исследования, но не само количество минут.

Миграция-кандидат P2-11 создаёт **приватный** список 486 потенциальных сочетаний (81 навык × шесть учебных действий). Он содержит только ссылки на программу/книгу, тип действия, наличие QA-контента, состояние академического рассмотрения. Не содержит вопросов, ключей, идентификаторов резервного банка, ответов учеников, новых оценок или учебных минут. Если источника/маршрута не хватает, обозначаем отсутствие явно, а не придумываем материал.

Особое правило: опубликованное учебное задание само по себе **не** является проверенной измерительной процедурой исправления ошибки. Все 81 действия типа correction отдельно помечены как требующие прямого наблюдения полного процесса исправления.

## 3. Минимальный протокол будущих добровольных измерений

1. **Согласие до наблюдения.** Отдельное осознанное разрешение, соответствующее возрасту ученика и требованиям к участию несовершеннолетних. Отказ не меняет доступ к iClub и академические результаты. Личный идентификатор заменяется псевдонимом; оригиналы и подтверждения хранятся только в защищённом исследовательском контуре, не в GitHub.
2. **Зафиксировать исходное знание.** До работы показать объективное состояние конкретного навыка (неизвестно / есть доказанный пробел / прежде подтверждено). Записать проверяемую ссылку на исходное состояние и версию методики. P1 и P5 нельзя смешивать.
3. **Выдать реальную разрешённую задачу.** Сохранить ссылку на опубликованный QA-контент без копирования формулировки или ключа в отчёт. Проверка, исправление, адресная практика, отсроченное повторение, смешанное задание и письменный метод изучаются раздельно.
4. **Учитывать только активную самостоятельную работу.** Отдельно остановки, посторонние дела, помощь учителя и неопределённое время вне iClub. Нельзя считать время открытия страницы, оставленную вкладку или лимит задания самостоятельным обучением. Несколько попыток одного учебного действия считаются **одним наблюдением ученика** с несколькими сегментами; это предотвращает псевдоповторение статистики.
5. **Сохранять успешные и неуспешные результаты.** Не выбрасывать трудные/незавершённые случаи ради красивой средней. Для письменного метода допустим только факт самостоятельной работы: сам ученик и AI не присваивают проверенный Cambridge методический балл.
6. **Независимая проверка обоснованности.** Проверить часы/минуты, исходное знание, методику, источник работы, пропуски, разброс между учениками, повторные попытки, перенос результатов на разные уровни подготовки и независимого академического утверждающего. Небольшая технически достаточная выборка НЕ становится популяционным научным нормативом автоматически.

## 5. Честный академический остаток

Действующие материалы и история ответов доказывают **какое действие нужно ученику**, но пока не доказывают, сколько именно минут требуется разным ученикам для выполнения этого действия. Даже реальные по времени наблюдения нуждаются в независимом рассмотрении; число участников и разброс должны быть обоснованы для решения, а не выведены из синтетического E2E.

**Следующий подэтап P2-12:** после появления согласованных реальных наблюдений провести отдельную академическую проверку групп, интервалов и рисков применимости и затем собрать полный расчёт с общими prerequisites, интервальным повторением, P1/P5 110/75-минутными полными попытками и разными экзаменационными датами. Только после этого — три явных действия ученика. Если независимых доказательств нет, программа показывает задачи без псевдоточных часов.
