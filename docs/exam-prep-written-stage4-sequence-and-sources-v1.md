## 1. Серверная последовательность

Применена аддитивная миграция Supabase **`20261022152815_iclub_exam_core_written_sequential_navigation_v1`**. Исходник сохранён в GitHub:
`supabase/migrations/20261022152815_iclub_exam_core_written_sequential_navigation_v1.sql`.

- Для native written plan допускается один `active` план по `learner_user_id/program_key/version_key` (уникальный частичный индекс).
- Закрытые `open_v1` и `advance_v1` проверяют, что отсутствуют незавершённые предшествующие письменные шаги того же плана.
- `advance_v1` требует `opened_at`, не принимает фиктивное эссе, оставляет запись лишь о переходе, не выставляя баллы.
- `criteria_v1` показывает требования только для открытого шага, закрытого в программе, одобренного по всем QA. Услуга AI или ментора для этого не требуется.
- Добавлен закрытый `private.iclub_exam_core_written_plan_next_v1`, выдающий только следующий разрешённый пункт. Никаких learner-facing grants или изменений host/UI.
- Синтаксически ошибочная первая попытка миграции была отклонена PostgreSQL без применения. Исправленная миграция принята, её фактическое определение и индекс проверены через SQL.

## 2. Разрешение контентного пробела: source material

Обнаружен и закрыт на уровне **черновых проектных файлов**, но не learner runtime, важный недостаток:
у заданий секции A P2/P4 не было привязанного текста источника/таблиц. Без них часть заданий не выполнима.

Создан:
`exam-prep/academic/economics-9708-P2-P4-sectionA-source-EN-DRAFT.json`.

- **P2 / Isara:** 3 поясняющих абзаца и 6 исходных показателей; связаны все 6 вопросов P2 Section A.
- **P4 / Nerava:** 3 абзаца, таблица торговли за два года, курс валюты; связаны все 4 вопроса P4 Section A.
- Это полностью оригинальные вымышленные учебные данные iClub, НЕ прошлые экзаменационные задания Cambridge.
- Файл помечен `INTERNAL_DRAFT_NOT_FOR_LEARNERS`, `runtime_enabled=false`, RU/UZ отсутствуют. Пока не одобрены академически и редакционно, данные ученикам не выдаются.
- Внешний syllabus Cambridge 9708, версия 2 (2026–2028), стр. 35–36 подтверждает, что Section A обязательно содержит source material: https://www.cambridgeinternational.org/Images/697423-2026-2028-syllabus.pdf.

**Согласованность:** 20 проверок JSON через GitHub, 0 отказов, включая связи со всеми 10 подпунктами A и расчёты:
P2 shortage `160−100=60` тыс. кг/неделю;
P4 goods/services balance Year A `−12`, Year B `−9` млрд USD; улучшение `+3`.
Из-за отсутствия primary/secondary income полный current account вывести нельзя.
Проверка расчётов **не равна** academic sign-off.

Для повторного локального QA в репозитории добавлен
`scripts/qa-economics-9708-written-source-v1.cjs`. В текущем этапе содержимое проверено в отдельном JS тесте по загруженным из GitHub файлам; GitHub QA script ещё не запускался через CI.
