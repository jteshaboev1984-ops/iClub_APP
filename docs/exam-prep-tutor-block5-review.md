### P1-CIR-01 — Degrees and radians

- 150 degrees = 5 pi / 6 radians.

### P1-CIR-02 — Arc length
Teach s = r theta with theta in radians, plus rearrangement for r or theta.
Reviewed example:
- r = 6, theta = 2 pi / 3 gives s = 4 pi.
Use the fraction-of-circumference interpretation as the alternative explanation.

### P1-CIR-03 — Sector area and segments
Teach A = 1/2 r^2 theta and how a segment/composite area is built by adding/subtracting known pieces.
Reviewed example:
- r = 8, theta = pi / 3;
- sector area = 32 pi / 3;
- triangle area = 16 sqrt(3);
- minor segment area = 32 pi / 3 - 16 sqrt(3).
Use the sector-minus-triangle model as the core segment idea.
