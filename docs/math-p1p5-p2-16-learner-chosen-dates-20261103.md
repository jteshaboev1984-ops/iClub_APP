# P2-16 — даты экзаменов выбирает сам ученик

**Решение архитектора, 03.11.2026.** Дата, которую ученик ввёл для Paper 1 или Paper 5, считается его датой экзамена **для индивидуального плана iClub**. Никаких подтверждений от школы, центра, наставника и запросов дополнительных документов. Предыдущее предложение подтверждать даты школой отменяется. Только пользователь решает, что указать и когда изменить.

## UX

В компактной временной линии Mathematics Exam Prep две кликабельные даты: **P1 📅** и **P5 📅**. Один тап открывает привычный нативный календарь телефона/браузера; в раскрывающемся редакторе можно выбрать/исправить обе даты, очистить любую, отменить правку. **Одна кнопка «Сохранить даты»** (ru/uz/en) применяется только после явного нажатия, без дополнительных подтверждений. Успех отображает короткое сообщение; ошибка остаётся видимой и допускает повторную попытку. Ввод — только день, без обязательного ввода часов/минут и без фиктивного «точного времени Cambridge». Произвольная будущая дата на следующие три года допустима независимо от ранее выбранной серии.

После сохранения сразу перерисовывается общая линия «начало → сегодня → экзамены», количество освоенных/оставшихся навыков и приблизительные часы из P2-14. Если введена одна дата, iClub показывает **недельный ориентир по этому одному экзамену**; если обе — **единый недельный ориентир Mathematics** для P1+P5 с двумя сроками. Время, уже выбранное учеником в профиле, **не меняется автоматически**. Даты можно изменить или удалить без сброса обученности.

## Данные и безопасность

Для личных дат — отдельная закрытая таблица `private.exam_prep_learner_exam_dates_v1` с ключом (пользователь, версия программы, P1/P5). Поле типа PostgreSQL DATE, отдельно от старых служебных appointment/status записей: они не перезаписываются. Пустое значение — явное удаление личной даты. Запись доступна только через owner-scoped `public.save_my_exam_prep_timeline_dates_safe_v1(date,date)` по существующему Exam Prep Core gate; RLS включён, прямой SQL-доступ anon/authenticated запрещён. Операция одной транзакцией сохраняет P1 и P5, возвращает обновлённый V2-расчёт, а не делает два последовательных запроса с частичным состоянием.

`public.get_exam_prep_simple_learning_timeline_safe_v1()` сначала берёт личные даты; до первого их ввода сохраняет совместимость с историческими appointment. Для личных дат отсутствует проверка серии «May/Jun», «Oct/Nov», поскольку ученик вправе указать свой день. Дата хранится без часового пояса; только для вычисления оставшихся недель математическая граница принимается в полдень по времени Ташкента, что не объявляется официальным временем экзамена. Проверка «не раньше завтрашнего дня» проводится и в браузере, и на сервере. При ошибке запись атомарно отклоняется.
