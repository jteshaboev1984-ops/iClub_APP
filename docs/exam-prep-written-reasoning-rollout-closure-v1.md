# Exam Prep Written Reasoning Rollout Closure v1

Status: governed closure of the current 67-task written-reasoning audit for the live Cambridge AS Mathematics P1+P5 Exam Prep module.

## Production boundary after Batch M1

The audited set contains 67 published reasoning/interpretation/method tasks. The current governed companion surface is intentionally smaller:

- 49 audited tasks have deterministic companion checks.
- 52 companion checks are published in total because two tasks legitimately use more than one check.
- 16 audited tasks remain without companions because they belong to protected paper/timed/holdout assessment surfaces.
- 2 audited learning tasks remain without companions by deliberate academic-design decision.

This is a closure state, not an incomplete target of 67/67. A companion check is added only when it can test a narrow prerequisite idea without disclosing the task-specific answer or replacing written/visual mathematical work.

## Learning tasks intentionally left without a companion

### `P1FUN07-W01` — P1-FUN-07

The task asks the learner to reflect graph points in the y-axis and x-axis and state the corresponding equations using `f`.

A short deterministic check on which coordinate changes sign, or on `f(-x)` versus `-f(x)`, would directly disclose the central method required by the task before the learner produces the written/graph reasoning. The original written task therefore remains the authoritative learning evidence without a companion check.

### `P5DAT05-W01` — P5-DAT-05

The task asks the learner to read cumulative-frequency positions, calculate IQR, convert a cumulative frequency to a percentage, and explain what cumulative frequency means in context.

A short deterministic check on the meaning of cumulative frequency would directly answer the required explanation in part (d); a quartile-position check would directly answer part (a). The original written/graph interpretation therefore remains authoritative without a companion check.

## Closure invariants

1. Existing written prompts, rubrics, responses and session history are immutable; companion content is additive only.
2. P1 and P5 evidence remain separate.
3. Companion results remain app-checked non-crediting support evidence and do not establish written-task mastery.
4. Written evidence remains self-reviewed unless an authorised mentor verifies it under the existing Mentor Care contract.
5. No published companion may appear in a protected paper, timed or holdout assessment.
6. `P1FUN07-W01` and `P5DAT05-W01` remain no-companion learning tasks unless a later academic-design review demonstrates a check that does not reveal the required task answer.
7. Expanding beyond the 49 checked audited tasks requires explicit review of this closure contract and the CI gates; it must not happen through a bulk seed or count-completion exercise.
