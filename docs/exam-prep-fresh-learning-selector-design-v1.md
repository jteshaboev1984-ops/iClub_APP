# Fresh learning selector — DRAFT design, 21 Sep 2026

Not approved for installation or publication. Scope: enrollment-gated Cambridge AS Mathematics Exam Prep only, no changes to real learner history, legacy Practice/Tours or academic thresholds.

Current read-only baseline: 45 P1 + 36 P5 skills, exactly one published learning assessment per skill; no reviewed second packs. A P1-CIR-01 learner finalized the same four-item assessment nine times. Selecting `ORDER BY id LIMIT 1` in the legacy plan and correction authorizers would keep repeating it even after publishing an alternative. The existing draft goal eligibility/start guards can block repeated assessment IDs, but do not yet select a different governed pack.

Required shared server selector: user + program version + component + exact primary skill; return the first never-exposed APPROVED and PUBLISHED learning assessment, or no candidate. Do not count a previously finalized assessment as fresh. Reject overlap of question IDs or written task IDs with any prior user session and with another published learning pack. Require an independently approved content version, assessment, question metadata, written rubric, math/EN/RU/UZ/copyright/technical checks, learning-only exposure roles, no held-out/reserved question. Use identical selection in read-only goal eligibility, Core correction/learning authorization, and pre-start. Preserve existing active session before deciding new eligibility. Lock user/component transactions; never silently replan, reissue consumed authorization or credit re-review. Zero candidate returns an honest waiting state; a prior finalized pack returns content exhausted; no new session or evidence.

Production metadata blocker discovered SELECT-only: three P5 published learning assessments (`p5_dat01_learning`, `p5_dat04_learning`, `p5_dat06_learning`) lack assessment-level `approved_at`, although their content versions and written tasks have approval. Do not invent timestamps, bypass the approval condition or change current production rows without an independent audit and specific approval. Tracked in #126.

Gate: independently authored new original P1-CIR-01 assessment first, then rolling expansion for all 81, three independent objective questions + written reasoning with all-language QA and no use of diagnostic/retest/mixed/unseen reserve. Until publication and selector end-to-end PostgreSQL/browser acceptance, this is design only. No SQL, merge, flag or enrollment authorized by this document. #113 #127.
