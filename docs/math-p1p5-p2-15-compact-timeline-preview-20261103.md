# P2-15 Mathematics P1/P5 — компактная временная линия (preview)

**Решение архитектора:** пользователь видит только начало подготовки → текущую дату → даты экзаменов, подтверждённое освоение, работу в процессе, ещё непроверенные навыки и **приблизительные часы**, рассчитанные ранее в P2-14 по 13 Cambridge-разделам. Никаких 486 строк академических норм, дополнительных обязательных опросников или автосбросов прогресса.

## Выполненные изменения (только draft PR #470)

- Новый изолированный компонент [exam-prep-simple-timeline-ui.js](https://github.com/jteshaboev1984-ops/iClub_APP/blob/feature/math-p1p5-workload-registry-v1-20261103/exam-prep/exam-prep-simple-timeline-ui.js). На действующей главной Mathematics Exam Prep над штатными карточками P1 и P5 отображается горизонтальная линия **начало / сегодня / экзамены**, две симметричные карточки статуса P1/P5 с полосой прогресса, общий остаток часов, выбранное недельное время и при двух подтверждённых датах — общий недельный ориентир Mathematics. Существующие кнопки, учебная навигация, ответы, оценки и план не меняются.
- Отдельный [адаптивный CSS](https://github.com/jteshaboev1984-ops/iClub_APP/blob/feature/math-p1p5-workload-registry-v1-20261103/exam-prep/exam-prep-simple-timeline-ui.css) с шириной под экраны 320/390/1440px, цветовыми различиями подтверждённого и ещё изучаемого, компактными отступами и ограниченными переносами.
- Все тексты полностью на ru/uz/en. Язык берётся из UI-предпочтения, не меняет язык предметного контента. При неизвестной дате вместо вымышленного недельного норматива показывается понятное сообщение «Укажите даты экзаменов P1 и P5»; рассчитанный общий остаток часов остаётся доступен.
- Читает только [owner-scoped P2-14 V2 RPC](https://github.com/jteshaboev1984-ops/iClub_APP/blob/feature/math-p1p5-workload-registry-v1-20261103/supabase/migrations/20261103041000_exam_prep_simple_cambridge_source_time_estimate_v1.sql), проверяет контракт 45+36 навыков, Cambridge-источник, непротиворечивость суммы и базовую авторизацию. Предыдущие запоздавшие ответы блокируются, если экран или предмет сменился; недостаточный доступ, ошибка RPC или неподходящие данные ничего не добавляют на экран. Никаких данных и результатов в localStorage.
- **Флаг по умолчанию выключен**: `window.iClubExamPrepSimpleTimelineUiEnabled !== true`. Без явного QA/архитекторского включения модуль сразу прекращает работу. Подключён исключительно через новые статические файлы в `index.html`; **прежний `exam-prep-api.js` восстановлен без единого байта изменений** (Git blob `e51053de286bf4c9f16fa7a608ad32ef55d203c8`).
- [Node/DOM smoke](https://github.com/jteshaboev1984-ops/iClub_APP/blob/feature/math-p1p5-workload-registry-v1-20261103/scripts/math-p1p5-simple-timeline-ui-smoke-v1.cjs) проверяет закрытый флаг, авторизацию, P1/P5 суммы и неверные данные, формат дат и чисел, три языка, отсутствие запроса для других предметов, stale RPC response.

Никаких настоящих ответов/ID учеников в скриншотах.

## Оставшиеся условия

Это **готовая к QA предварительная версия экрана, НЕ публичный запуск**. Активация интерфейса и применение нового RPC к production требуют отдельного решения; не менять автоматически доступ, недельный бюджет, результаты, Practice/Tours, сертификаты, даты экзаменов или оценки. Текущий P2-14 расчёт — ориентир iClub по историческим Cambridge teacher-guided topic hours, не официальное время самостоятельной подготовки от Cambridge и не гарантия оценки.

При следующей продуктовой доработке можно дать ученику возможность **вручную подтвердить реальные даты и время P1/P5** у своей школы (с сохранением только после явного действия), чтобы появлялся недельный ориентир. Пока отсутствие индивидуальных дат не исправляется подставлением календарных допущений. Публичный GO остаётся закрыт.
