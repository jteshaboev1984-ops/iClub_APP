## Retest-strength review

A delayed retest must be materially different from the teaching item. The second review identified several draft retests that were mathematically correct but too close to routine learning practice.

Thirteen retest items were therefore strengthened while still draft and history-free:

- P1-QUA-01 R03/R04: moved from direct repeat calculation to unique-level/vertex interpretation.
- P1-QUA-02 R03/R04: moved to positivity-for-all-real-x and line/parabola tangency.
- P1-FUN-01 R03/R04: moved to inverse-branch/domain reasoning and composition-domain restriction.
- P1-FUN-02 R03/R04: moved to open-endpoint range reasoning and a different function family.
- P5-DAT-02 R03: now requires updating a stem-and-leaf median after a new observation.
- P5-DAT-04 R03/R04: now requires comparing histogram heights/areas rather than repeating a one-step density calculation.
- P5-DAT-06 R03/R04: now requires inverse frequency reasoning and analysing how an extreme-value change affects mean/median/mode.

These changes improve evidence independence without changing the canonical skill ownership.
