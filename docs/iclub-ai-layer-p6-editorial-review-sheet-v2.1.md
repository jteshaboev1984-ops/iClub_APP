## Что именно следует утвердить

1. **Точность инструкции:** реальное место входа; для четырёх нижних вкладок — нижнее меню, для «О проекте» — Главная, для «Поддержка» — Профиль.
2. **Язык и доступность:** естественное обращение к школьнику, соответствие существующим локализованным подписям, читаемость на мобильном устройстве, отсутствие двусмысленностей.
3. **Область применения:** пока только навигация. Ни один текст не содержит и не должен подразумевать анализ успеваемости, рекомендации предмета, готовность к экзамену или доступ к данным другого ученика.

**Особая деталь EN:** надпись кнопки открытия страницы About — **“About project”**, не заголовок самой страницы **“About”**. Смена реального UI требует новой проверки инструкций на всех языках.

## Незакрытые решения

**Редакционное заключение:** отсутствует. **Подтверждение правообладателя:** отсутствует. **Независимая проверка безопасности/доступности:** отсутствует. **Разрешение архитектора на выпуск:** не предоставлено.

Home next-actions — **отдельный продуктовый вопрос**: определить, какие академические действия допустимы, кто отвечает за приоритеты, на основании каких подтверждённых данных они выбираются и что происходит при неверных/отсутствующих данных. Существующие Activity counters/Profile и локальная история не заменяют такой план.

После утверждения текста должны быть отдельно пройдены version/hash/rights/locale publication и защищённая end-to-end интеграция; автоматическое выставление флагов одобрения запрещено.
