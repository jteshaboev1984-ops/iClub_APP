# iClub AI v2.1 — экранная логика для настоящего Preview

Версия для визуальной приёмки, 15 октября 2026. Основание: Master Plan v2.1, решения 1A–44A, действующий index.html последнего production-коммита ab96c88b. Все предложения ниже требуют визуальной приёмки архитектора; НЕ разрешают Global AI release.

**Главный UX-принцип:** одна точка входа iClub AI над нижней навигацией, разные действия по текущему реальному экрану. На мобильном нижняя панель 78% высоты с раскрытием, на десктопе боковая панель справа. Общая помощь по приложению отличается от предметных объяснений. При переходе между экранами панель закрывается; предметные чаты нельзя смешивать; без source/прав нет фантазий о результатах.

| Экран приложения | Что показываем | Что делает AI после серверного допуска | Что запрещено |
|---|---|---|---|
| Splash, регистрация, подтверждение сертификата | Без AI | — | Не читать личные данные |
| Главная | Единый значок, 2 быстрых запроса. В будущем рядом с подтверждённой карточкой — «Почему этот шаг?» | Поясняет приоритет: завершённая Practice с ошибками → открытый Tour → продолжение записанного предмета | Не выдавать персональный план без подписанного сервером evidence |
| Обучение: каталог | Общая помощь | Как выбрать предмет и начать учебный путь | Не угадывать способности |
| Предмет/тема | «Объяснить тему» только после readiness | Краткая теория, пример, шаги из утверждённого источника соответствующего языка | Нет источника — «В разработке», а не свободная фантазия |
| Видео | Помощь с процессом обучения | Конкретные таймкоды только по проверенному transcript | Нельзя утверждать, что AI видел ролик |
| Practice до начала | Объяснение правил | Как проходит упражнение и что будет после | Нельзя подсказывать ответы |
| Practice во время всех вопросов | НЕТ AI-значка | Backend также отказывает любому маршруту | Никаких ответов, готовых карточек и кэша |
| Practice итог | «Объяснить результат» | Объяснить подтверждённые итоги после финализации | Без изменения score |
| Practice исправление | «Помочь понять ошибку» у конкретного вопроса | Пояснение причин, теория, следующий запрос на повторение | Нет подмены правильного ответа и изменения истории |
| Tour активен/закрыт | AI недоступен | — | Нет доступа к ключам/закрытому архиву |
| Tour официально открытый архив | «Объяснить итог», «Разобрать вопрос» | Точный разрешённый результат и подтверждённая теория | Окончание тура само по себе не открывает AI |
| Mathematics Exam Prep обзор P1/P5 | Сохраняем рабочий Tutor, без нового дублирующего знака до parity | Позднее раздельное объяснение результатов P1 и P5, 243 утверждённых карточки | Никакого общего P1+P5 mastery и двойного списания |
| Exam Prep диагностика/retest/timed/mock paper | НЕТ AI | — | Полный blackout |
| Exam Prep после проверок | Контекстная помощь только после parity | Объясняет ошибки, roadmap, следующий шаг; академический judgement человека не присваивает себе | Не меняет marks/mastery/readiness |
| Profile | «Объяснить прогресс», если есть подписанные агрегаты | Расшифровать показатели по предметам | Не придумывать персональный анализ из DOM или локальных % |
| Ratings/Certificates/About/Support | Общая помощь по действующим правилам | Помочь понять, где находится функция | Не менять места, права, сертификаты |
| English/SAT и неготовые темы | Только общий AI | «В разработке» плюс проверенные альтернативы | Не отвечать из неподготовленных материалов |

**Цикл запроса:** разрешён экран → готовность предмета/темы/языка → авторизация владельца и конкретного объекта → источник и тариф → атомарный лимит/бюджет → точный ответ → повторная проверка актуальности и protected state → доставка. На любом сбое нет академических записей и нет платного начисления за невыданный ответ. Тестовые 1:3 / Free=3, Plus=9, Pro=14 на пять часов НЕ являются финальными ценами/разрешением расхода.

**Preview:** рабочий код APP остаётся исходным, рядом загружается только визуальная боковая/нижняя панель по явному URL-параметру на Vercel Preview. Примерные тексты НЕ являются реальной генерацией, AI не подключается к Supabase/провайдеру, не читает оценки. Если приложение использует production Supabase через штатный app.js, никакие новые регистрации/Practice/Tours ради AI делать нельзя. Для просмотра нужен уже имеющийся безопасный учебный аккаунт; новая демонстрация не создаёт аккаунт и не трогает академическую запись.
