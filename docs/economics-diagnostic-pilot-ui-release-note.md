# Economics Diagnostic Pilot — UI Release Note

Date: 2026-07-03

The current work is data-layer only.

The next UI work should be a hidden demo path, not a replacement of the live practice or tour flow.

Student screens should show:

- whether the answer is correct;
- a short explanation of the mistake;
- weak topic or subtopic;
- next recommended action.

Student screens should not show:

- database table names;
- function names;
- diagnostic IDs;
- rule JSON;
- answer keys before submission.

Production history must remain stable during the pilot.
