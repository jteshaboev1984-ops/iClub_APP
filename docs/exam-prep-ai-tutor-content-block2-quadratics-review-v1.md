## Skill boundaries and reviewed example choices

### P1-QUA-02 — Discriminant and roots

Canonical action:
Use the discriminant to determine the number/type of real roots, including parameter conditions.

Tutor example:
x² - 4x + k = 0
D = 16 - 4k
- two distinct real roots: k < 4
- repeated real root: k = 4
- no real roots: k > 4

Why this example:
One compact parameter example demonstrates all three discriminant cases without solving the quadratic.

Exclude from this card:
general quadratic-solving method comparison, completing-the-square procedure, quadratic inequalities.

### P1-QUA-03 — Solving quadratic equations

Canonical action:
Solve quadratic equations and choose factorisation, quadratic formula or completing the square appropriately.

Tutor example:
x² - 5x + 6 = 0
(x - 2)(x - 3) = 0
x = 2 or 3

Teaching emphasis:
Method selection rather than forcing one method. Formula is shown as the general route; completing the square is positioned as a valid route when form/graph information also matters.

Exclude from this card:
discriminant classification as a separate decision skill; inequality intervals; transformed-variable quadratics.

### P1-QUA-04 — Quadratic inequalities

Canonical action:
Solve quadratic inequalities with correct interval endpoints.

Tutor example:
x² - 5x + 6 > 0
roots 2 and 3
answer x < 2 or x > 3

Paired contrast:
x² - 5x + 6 ≤ 0 gives 2 ≤ x ≤ 3.

Teaching emphasis:
roots → sign regions / graph position → endpoint inclusion.

Exclude from this card:
general root classification by discriminant; solving simultaneous systems.

### P1-QUA-05 — Linear–quadratic systems

Canonical action:
Solve a simultaneous system containing one linear and one quadratic relation.

Tutor example:
y = x + 1
y = x² - 3x + 1
→ x = 0 or 4
→ solutions (0, 1) and (4, 5)

Teaching emphasis:
substitution/equating expressions, solve resulting quadratic, return both coordinates, interpret as intersections.

Exclude from this card:
general coordinate-geometry formulas; circle intersections/tangency.

### P1-QUA-06 — Reducing to a quadratic

Canonical action:
Recognise and solve equations that are quadratic in a transformed expression.

Tutor example:
x⁴ - 5x² + 4 = 0
u = x²
u² - 5u + 4 = 0
u = 1 or 4
x = ±1, ±2

Teaching emphasis:
recognise repeated expression, temporary substitution, solve ordinary quadratic, back-substitute, check restrictions.

Exclude from this card:
unrelated substitution techniques or post-P1 polynomial methods.
