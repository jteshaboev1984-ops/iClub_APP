# Stage 03 — проверка переходов Practice (QA)
Дата: 2026-10-09. Только QA, без изменения production.

## Утверждённые переходы
- **Пауза** в обычной Practice или по теме → сохранить черновик → открыть Practice (с той же выбранной вкладкой) → показать «Продолжить попытку».
- **Верхняя стрелка** во время Practice → то же безопасное действие «Пауза». Во время отправки ответа обе кнопки блокируют выход.
- **Верхняя стрелка** из главного экрана Practice → карточка предмета (Mathematics).
- **Верхняя стрелка** из результата Practice → Practice; из просмотра ответов или рекомендаций → результат.
- **Продолжить попытку** → восстановить вопросы/ответы/таймер через действующий safe API; при ошибке не терять незавершённую попытку.
- **По турам / По темам** → только переключение интерфейса; не создаёт новых попыток и не меняет базу.
- **Выбор темы** при сохранённой попытке → «Продолжить попытку» либо «Не сохранять и сменить тему»; выход из окна ничего не отменяет.
- **Назад к результату** → завершённый результат без возвращения в задания.
- **Пройти снова** → новый запуск по существующим правилам, завершённая история сохраняется.
- **К практике** из результата самостоятельной темы → Practice; для рекомендательного задания существующий возврат к рекомендации сохраняется.
- Нижняя навигация не выводит из активных вопросов Practice без паузы.
- Tours и Exam Prep маршруты не менялись.

## Покрытие
- Проход сценариев верхней стрелки, паузы, корня Practice, результата, рекомендаций и просмотра ответов — автоматический contract.
- Три языка RU/UZ/EN для «Продолжить попытку».
- UI Chromium: 12 адаптивных тестов вкладок (320/360/390/430 × RU/UZ/EN).
